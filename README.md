# The Funniest Honest Appliance Error

A printer's error message, in its own flat, put-upon voice: it has eaten your
boarding pass, it was the only copy, and it regrets nothing.

## Run

```sh
node main.ts
```

Writes one line to `/output/entry.txt`.
